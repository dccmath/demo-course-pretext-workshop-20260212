Example 9.
Here is a “2-to-5” code \(C\text{:}\)
🔗
00 \(\longleftrightarrow\) \(\mathtt{00000}\)
01 \(\longleftrightarrow\) \(\mathtt{01011}\)
10 \(\longleftrightarrow\) \(\mathtt{10101}\)
11 \(\longleftrightarrow\) \(\mathtt{11110}\)
🔗
The set of source words are \(S = \{00,01,10,11\}\text{.}\) We can also write this as \(S = \mathbb{Z}_{2}^{2}\text{.}\) The set of codewords is \(W = \{00000,01011,10101,11110\}\text{.}\) Note that \(W \subseteq \mathbb{Z}_{2}^{5}\text{,}\) but \(W \neq \mathbb{Z}_{2}^{5}\text{.}\) We write the code as a table with double arrows \(\longleftrightarrow\) to emphasize the fact that every source word corresponds to exactly one codeword, and vice versa (that is, the code is a bijective function). We can describe this code as a “binary block code with block length 5”.
